# 可能需要的扩展

以下清单避免遗漏后续问题。主任务和回传优先；“已整理”不等于“默认全部运行”。先在RUN_SUMMARY写出触发证据，再判断是否需要用户确认。

| 项目 | 用途及前提 | 执行边界 |
| --- | --- | --- |
| 每队列轨迹着色、CNV三组分面 | 识别主体树是否受单一队列支配 | 从主对象展示，不重新建树；主任务诊断可直接做 |
| PCA/Harmony MST结构对照、逐队列留出MST | 核查连接结构对表示与来源的依赖 | 可作主任务轻量敏感性；准确写未重训表示/曲线 |
| 仅有患者标签支持的描述汇总、治疗/QC/周期分层展示 | 排查样本支持、处理和细胞质量解释 | 保留主对象全部细胞；另表注明比较范围；不加未授权P值 |
| 关键基因沿路径表达热图 | 更具体地解释功能动态 | 先固定基因来源、数量和分箱；不按最漂亮的CNV趋势挑基因；描述性 |
| 223,736正常/癌旁+CRC共同拟合 | 回到此前全来源设计，比较组织背景 | 输入已保留，须用户确认后另建版本；不替换CRC主树，不把Normal设为起点 |
| 原始PCA上的完整Slingshot曲线重拟合 | 若MST差异提示表示依赖 | 需另列任务与版本；与MST-only不同，不覆盖主模型 |
| Monocle2排序基因/批次回归敏感性 | 检查轨迹是否由固定选择主导 | 先说明设计，确认后全量独立重拟合；不为分出CNV三组调参数 |
| 全基因动态检验、BEAM、tradeSeq | 识别拟时序/分支相关表达 | 先确认患者重复、协变量、受检基因背景、检验族及BH；不自动开始 |
| 趋势模块及GO | 概括描述性模式 | 先固定趋势基因、聚类方案和GO背景；GO含推断统计，需确认设计 |
| PROGENy/代谢扩展 | 补充其他功能视角 | 使用核实的许可资源与固定评分方法；不混同于6套主Hallmark得分 |
| 真实恶性上皮限制分析 | 回答严格恶性细胞内的问题 | 目前未建立独立恶性判定金标准，不能将CRC或High直接当恶性 |
| RNA velocity、CytoTRACE、Monocle3等 | 不同问题或方法 | 本次未授权；没有真实剪接层不能做velocity，也不能替换Monocle2 |
| 独立队列投影、DNA/空间/临床验证 | 扩展外部验证 | 需要独立材料和新任务，不能用本批方法相关替代 |

若某项科学证据不足，写清缺少的字段/材料；不要编造参考根、恶性标签或扩展结果。
