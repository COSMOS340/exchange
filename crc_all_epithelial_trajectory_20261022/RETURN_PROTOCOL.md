# 结果回传协议

## 结果目录

所有输出放本任务的 `results/`：

- `01_图形/`
- `02_表格/`
- `03_对象/`
- `04_日志和检查/`
- `code/`
- `RUN_SUMMARY.md`
- `01_逐图阅读指南.md`
- `02_方法与限制.md`

必须包括Monocle2与Slingshot对象、逐细胞拟时序、树/路径表、来源映射、动态基因及GO全表、Hallmark活动、输入/代码/参数/环境绑定、数值检查和视觉检查。不要重复上传1.18GB原始输入。

## GitHub回传

1. 在本仓库新建结果分支，不覆盖main或旧结果分支。
2. 提交代码、小型表格、运行摘要和清单；大型对象与图包放结果Release。
3. 建议结果标签：`crc-all-epithelial-trajectory-results-v1-20261022`。若远端已存在，使用递增的新标签，不用 `--clobber`。
4. 每个附件上传前后核对文件名、字节数和SHA256；保存Release清单。
5. 回报分支、commit、Release链接、完成/失败/未做清单和仍需Mac验收的项目。

不得上传访问令牌、SSH密钥、系统配置、患者直接身份信息、整篇版权PDF或用户提供的范文截图。

## Mac端验收

Mac按结果清单下载并核对SHA256，解压到第14步新的接收目录。只有在223,736细胞、来源分类、树/根、动态统计、全部图形和日志均通过复核后，才更新第14步正式入口。旧CRC-only结果保留为敏感性分析，不删除。
